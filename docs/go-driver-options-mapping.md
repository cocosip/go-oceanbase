# Java 配置逐项迁移清单

基线：obconnector-j 2.4.14，提交 `6adc311ba5db8b2f19f98f3e6e4734667fdfdda1`。DefaultOptions 共 **160 项**，每项保留固定源码链接、Java 字段初值与拥有任务；D32 补正原155项提取遗漏的5个带空格枚举。历史别名、枚举外入口和初始化联动见后文；清单和默认值核对齐全不等于功能完成。

当前已进入 D32 逐项收口，D28/D30/D31 的目标平台运行及真实服务验证待补，不作为全部本地开发的阻塞；“配置已实现”不表示对应网络/SQL 功能可用。未列入 ParseDSN 白名单的 Java 名称一律拒绝，不透传给服务端。每行关联具体本地测试入口；测试证明的范围、归类和剩余条件见 §5，后续随行为变更维护。

Go DSN 使用 `oceanbase://user:password@host:2881/database`，各段按 net/url 转义。基础选项：mode、prepareMode、connectTimeout、readTimeout、skipVersionProbe、charset、collation、ncharset、location、parseTime、rowsAffectedMode、resetMode、allowMultiStatements、interactive、proxyUser、createDatabaseIfMissing、maxMessageBytes、maxLOBBytes、fetchSize、maxResultItems、cleanupTimeout；认证新增 allowOldPassword、passwordCharset。后续协议/执行/路由/发现选项见对应章节及白名单。所有选项拒绝重复/空值；时间使用 Go duration，布尔只接受 true/false。凭据只放 userinfo；logger/TLS/回调和 ConnectionAttributes map 只能程序化注入。`connectTimeout` 是两端同名但单位和零值含义不同的选项，必须显式迁移，见 §4。

Config 默认：建连 10 秒，逻辑消息 64 MiB，LOB 物化 16 MiB，fetch 128 行，摘要 1024 项，清理 1 秒；零值选默认，负值拒绝。TLS 配置克隆其证书字节、证书池、切片/map；回调、私钥、已解析 x509.Certificate（含 Leaf 和 AddCert 证书）、ClientSessionCache 及 logger 仍为调用方共享的不可变/并发安全对象。

## 1. 规范选项及字段初值

“Java 字段初值”来自固定 [Options](https://github.com/oceanbase/obconnector-j/blob/6adc311ba5db8b2f19f98f3e6e4734667fdfdda1/src/main/java/com/oceanbase/jdbc/util/Options.java#L60)，逐项链接其字段；未显式赋值的 Java 基础类型取 false/0，引用取 null。已用未修改的 Options 源码在独立 JVM 中反射核对160项，不由枚举说明文字推测。数字单位沿用左侧 DefaultOptions 的定义，字符串按原值列出。

这些值是未提供参数、DriverManager 登录超时为0、未加载凭据插件时的起点，**不是所有连接路径的最终值**：connectTimeout 可受 JVM 登录超时影响，socketTimeout 由 HA 模式补值，三态布尔和其他初始化联动见 §4。Go 不依赖 JVM 属性或 Java 插件。

“归类 / 本地测试入口”验证右侧 Go 承载或拒绝边界，不表示接受左侧 Java DSN 名称，也不表示 Java 的全部行为已等价实现。应用责任、平台适配和不适用项尤其需要结合 §5 阅读。

## 4. 初始化联动、默认差异及零值

Java [DefaultOptions.parse](https://github.com/oceanbase/obconnector-j/blob/6adc311ba5db8b2f19f98f3e6e4734667fdfdda1/src/main/java/com/oceanbase/jdbc/util/DefaultOptions.java#L1397)以 new Options 或传入的旧 Options 为起点；同名 Properties 优先于 URL 参数。布尔值经过小写转换后接受空值/1/true 与 0/false；URL 内重复的相同 key 不覆盖先前加入的值。不同别名指向同一字段时，不应依赖 Properties 的枚举顺序解决冲突。Go 只有一个明确 Config 快照；query 名称区分大小写，重复/空值拒绝，布尔严格为 true/false。

## 5. 逐项测试证据的范围

| 归类 | 本地证据所验证的内容 | 不应推断的结论 |
| --- | --- | --- |
| Go 配置 | 现有 Config/DSN 的校验、快照或对应本地协议行为，具体以链接测试中的断言为准 | 只运行配置测试不能证明真实服务端行为；一行多个入口也不代表全部组合已验收 |
| 标准库 | database/sql、net、tls 或外部注入 slog 的 Go 用法；链接 Example 没有 Output 时只编译，运行证据来自旁边 Test | 不实现第二套连接池、TLS 或日志全局设置；不推断远端网络、OS 策略和部署监控结果 |
| 显式 API | Go 的 Batch、LOB、Cursor、Metadata、XA 等公开操作及本地对端行为 | 不提供同名 JDBC 类或配置开关；不把不同执行策略、计数语义或优化性能视为等价 |
| 固定语义 | Go 返回类型、严格转换、资源边界或固定执行策略 | 不保留 Java 兼容开关；编解码/查询计划测试不能证明服务器字典、权限和优化性能 |
| 安全拒绝 | 关闭 TLS 校验、未认证公钥等输入被拒绝，或使用明确的安全替代路径 | 拒绝测试不等于被拒绝的弱化功能已实现 |
| 应用责任 | 驱动接受已加载的证书/公钥、回调、标准池和诊断入口；旧 DSN 名称被拒绝 | Java store 解锁/格式转换、凭据来源服务、JMX 替代监控和运行时栈采集不由驱动实现，未据此声明它们通过 |
| 平台适配 | 当前主机上实际运行的原生传输/系统 ABI；构建标签和执行范围见进度/兼容矩阵 | Windows 本地替身和宿主 ABI 测试不替代真实 Linux VC；NTLM 不替代域 Kerberos/Negotiate |
| 不适用 | `galeraAllowedState` 属于其他产品，Go DSN 明确拒绝 | 不伪造 OceanBase 对应状态查询，也不计为已支持的服务端能力 |

[TestDSNJavaCanonicalOptions](../dsn_java_options_test.go) 固定全部160个规范名称，逐项验证 ParseDSN 与标准 sql.Open 的配置入口：158个 query key 返回脱敏的未知选项 ConfigError；仅 `connectTimeout`、`servicePrincipalName` 保留同名 Go 入口，并检查解析后的实际字段。前者仍使用 Go duration，不能据名称相同推断 Java 毫秒或零值语义。该测试不连接数据库，不读取文档生成预期值，也不把158次拒绝算作158项功能验证；历史别名和枚举外参数仍由 [TestDSNJavaMigrationBoundary](../dsn_migration_test.go) 单独覆盖。

[TestMySQLScalarCompatibility](../scalar_compatibility_test.go) 通过 database/sql 验证 TINYINT（含显示宽度1及 unsigned）、YEAR、BIT(1)/BIT(64) 的实际返回值、ScanType、DatabaseTypeName、NULL、字节保留及后续 Ping；覆盖文本/服务端预处理/客户端预处理和标准/压缩/OB20 共9条本地路径。固定返回整数或原始字节，不引入 Java 类型猜测开关；对端提供的显示宽度和年份范围不证明真实服务端建表或范围校验。

所有源码链接指向测试入口所在文件；同一测试可支撑多个选项的共同 Go 替代，不重复估算完成数。TestMetadataCatalogAndRemarks 通过公开 Metadata 覆盖两模式、utf8mb4/GBK 和三包流的12场景：Catalogs/Schemas/Tables/Columns 的空值及四种非空 Catalog 请求、表/列备注的中文/空白/NULL 与重复查询。独立 SQL 预期验证精确过滤和备注投影，本地对端返回固定行集，不执行字典 SQL；TestMetadataCatalog 的 DDL 备注与 Catalog 对照仅编译，真实字典、权限和版本语义仍未验收。Unix 系统 GSSAPI、域认证、真实 Linux VC、Linux/macOS 运行、远程 CI 和成功 race 仍待取证；真实 OceanBase/OBProxy 联调按当前约束暂不执行。完整必需验证集继续使用开发进度 §5，D28/D30/D31/D32 不因增加链接而计为完成。
