# Java Configuration Migration Inventory

Baseline: obconnector-j 2.4.14, commit `6adc311ba5db8b2f19f98f3e6e4734667fdfdda1`. DefaultOptions contains **160 options**, each retaining pinned source links, the Java field's initial value, and its owning task. D32 corrects five enum entries containing spaces omitted from the original 155-option extraction. Historical aliases, extra-enum entry points, and initialization interactions follow below; a complete inventory/default comparison does not mean features are complete.

D32 now performs per-option completion checks. Target-platform runs/real-service verification for D28/D30/D31 remain outstanding without blocking all local development; “configuration implemented” does not mean the corresponding network/SQL feature works. Reject all Java names outside the ParseDSN allowlist rather than forwarding them to servers. Each row links specific local tests; see §5 for their scope, categories, and remaining conditions, and maintain these links as behavior changes.

Go DSNs use `oceanbase://user:password@host:2881/database`, with net/url escaping per component. Basic options: mode, prepareMode, connectTimeout, readTimeout, skipVersionProbe, charset, collation, ncharset, location, parseTime, compatibleMysqlVersion, rowsAffectedMode, resetMode, allowMultiStatements, interactive, proxyUser, createDatabaseIfMissing, maxMessageBytes, maxLOBBytes, fetchSize, maxResultItems, cleanupTimeout; authentication adds allowOldPassword and passwordCharset. See the corresponding sections/allowlist for later protocol/execution/routing/discovery options. All options reject duplicates/empty values; times use Go durations and booleans accept only true/false. Credentials belong only in userinfo; inject logger/TLS/callbacks/ConnectionAttributes maps programmatically. `connectTimeout` has the same name in both drivers but different units/zero-value semantics and requires explicit migration; see §4.

Config defaults: 10-second connection budget, 64 MiB logical messages, 16 MiB LOB materialization, 128-row fetch, 1024 summary items, 1-second cleanup. Zero selects defaults; negatives reject. TLS cloning copies certificate bytes, certificate pools, slices/maps; callbacks, private keys, parsed x509.Certificate objects (including Leaf/AddCert certificates), ClientSessionCache, and logger remain caller-shared immutable/concurrency-safe objects.

These values are starting points without parameters, with DriverManager login timeout 0 and no credential plugins, **not final values for every connection path**.
