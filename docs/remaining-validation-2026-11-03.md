## What still needs external support or a protocol contract

- **TLS/mTLS:** an SSL-enabled test endpoint plus CA/client certificate material. The current endpoints are intentionally plaintext; client TLS code already exists.
- **Compression:** an endpoint that actually offers the MySQL compressed protocol. Current OB20 success does not prove compressed OB20 or MySQL compression.
- **Proxy/cluster/fault recovery:** real ODP/multiple nodes, routing/control-plane fixtures and permission for controlled failures. Direct-target client receipt loss is now tested, including MySQL XA recovery; it does not prove node/process crash, durable coordinator restart or proxy failover. Oracle XA uses combined PL output and is not covered by the single-OK receipt-loss fixture. Full-link trace collection needs its real collector.
- **Identity/authentication:** a second test identity/proxy grant and actual plugin/KDC endpoints. Native ABI fixtures do not establish deployment authentication. Least-privilege metadata needs the intended restricted account.
- **Native RECORD/ANYDATA/locator input:** a supported target/version and documented successful bind wire. RECORD's five conventional schema/package/type metadata layouts all returned 600/HY000 in the raw probe; the tested combined RECORD and ANYDATA OUT calls with NULL output placeholders returned 600/0A000 (-4007). This does not mean PL-local RECORD or ANYDATA are absent, nor does it prove every possible input layout unsupported. No SQL wrapper is presented as native binding.
- **SRID 4326:** target spatial-reference support/dictionary provisioning in a separate authorized test environment. Current native and pure SQL operations both reject it; the driver does not provision SRS entries.
- **Oracle named region:** a target with America/New_York timezone support is needed for positive region/DST session acceptance. The current target returns 1882 from both session initialization and an independent ALTER SESSION control; numeric-offset LTZ/TZ storage remains usable and tested.
- **PREPARE 1295 fallback:** a real SQL/version fixture returning 1295. Nine nonexecuting PREPARE probes per mode produced successful preparation or syntax errors 900/1064, never 1295. Existing peer-tested fallback remains limited to a failed standalone prepare; business SQL is never replayed.
- **Remaining deployment acceptance:** Linux/macOS native runtimes, and an agreed endurance/performance workload. WSL is not installed on this host, and no Docker command is available. Cross-building is not native execution.

The established C08/C09/C10/C11 boundaries remain intentional: bounded MySQL multi-statement LongData, eligible scalar DML pipeline, row/message ownership under `database/sql`, and Oracle warning count without a verified detail API. They are not expanded into speculative APIs. U01's proven temporal/national shapes are implemented; unavailable native shapes and deployment acceptance remain explicitly open.

The temporal fixtures change only their own connection-local SQL_MODE and restore its original value. No global SQL_MODE, timezone dictionary or grants are modified. The numeric TYPE_OWNER token is not assumed to be a user ID or translated into an owner name.
